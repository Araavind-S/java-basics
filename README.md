# Java Basics

Practice programs from my journey learning Java from scratch, as part of preparing for a career move into software development engineering in test (SDET).

## Tools
- Java 21
- IntelliJ IDEA Community Edition
- Git and GitHub

## What's inside

| File | Topic | What it does |
|---|---|---|
| `Main.java` | Variables and data types | Stores and prints values, basic math, Celsius to Fahrenheit |
| `Decisions.java` | if / else | Positive/negative/zero, even/odd, grade calculator, leap year |
| `Loops.java` | for and while loops | Counting, multiplication table, sum of evens, factorial, digit count, star pattern |
| `Challenges.java` | Problem solving | FizzBuzz, prime checker, reverse a number |

## How to run
1. Clone the repo: `git clone https://github.com/Araavind-S/java-basics.git`
2. Open it in IntelliJ IDEA
3. Open any file and click the green arrow next to `main`

## What I learned
- Variables, data types, and why integer division loses decimals
- Conditions with `if`, `else if`, `&&`, and `||`
- Loops, nested loops, and variable scope
- Writing and testing edge cases (0, 1, negative numbers)
